# F1 — Euler-Produkt nicht wesentlich benutzt

**Tier 1** (fatal — widerlegt die Idee sofort)  
**Betroffene Ansätze:** 7 von 45 (15.6 %)

> Das Argument benutzt nur Funktionalgleichung, Fortsetzung und Wachstum.

## Worum es geht
