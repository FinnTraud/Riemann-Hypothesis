# F10 — Analogie ohne Trägerobjekt (Geometrie-Transfer)

**Tier 2** (blockierend — offener Kernschritt)  
**Betroffene Ansätze:** 10 von 45 (22.2 %)

> Die Konstruktion existiert im Funktionenkörperfall, das entsprechende Objekt über Z fehlt.

## Worum es geht
Weils Beweis lebt auf der Fläche C × C mit Frobenius und Schnittform. Ueber Z fehlen: die zweite Dimension (Produkt über einer absoluten Basis), ein Frobenius und eine polarisierte Schnitttheorie in der richtigen Dimension.

## Prüffrage
> **Welche Fläche, welcher Frobenius, welche Polarisierung? Wenn eines fehlt, ist das Argument leer.**
