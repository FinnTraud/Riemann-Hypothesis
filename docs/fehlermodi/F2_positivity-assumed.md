# F2 — Positivität angenommen statt bewiesen

**Tier 2** (blockierend — offener Kernschritt)  
**Betroffene Ansätze:** 7 von 45 (15.6 %)

> Weil-/Li-/de-Branges-Positivität wird vorausgesetzt oder aus einer äquivalenten Annahme gezogen.

## Worum es geht
RH ist zu mehreren Positivitätsaussagen äquivalent. Wer die Positivität aus einer Struktur ableitet, die selbst RH voraussetzt (oder aus der 'Erwartung' der Spektralität), argumentiert zirkulär. Im bewiesenen Fall stammt die Positivität aus dem Hodge-Index-Satz - also aus Geometrie mit Polarisierung.

## Prüffrage
> **Woher genau kommt das Vorzeichen? Gibt es eine polarisierte Geometrie, die es erzwingt?**
