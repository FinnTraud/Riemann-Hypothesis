# F8 — Paritätsbarriere (Sieb-/Multiplikativitätsmethoden)

**Tier 3** (strukturell — kann prinzipiell nicht implizieren)  
**Betroffene Ansätze:** 2 von 45 (4.4 %)

> Sieb- und Korrelationsmethoden können die Möbius-Parität nicht auflösen.

## Worum es geht
Selbergs Paritätsproblem: Siebe unterscheiden nicht zwischen gerader und ungerader Anzahl von Primfaktoren. μ(n) misst genau diese Parität; die für RH nötige Einzelsummen-Schranke M(x) << x^(1/2+eps) liegt jenseits dessen, was gemittelte Resultate liefern.

## Prüffrage
> **Beruht das Argument auf Sieben oder auf gemittelten Korrelationen? Dann kann es die Einzelsumme nicht erreichen.**
