# F9 — Abgeschnittenes Modell bewiesen, Limes offen

**Tier 2** (blockierend — offener Kernschritt)  
**Betroffene Ansätze:** 5 von 45 (11.1 %)

> Für jeden Cutoff N gilt die Aussage; der gleichmäßige Grenzübergang N -> unendlich fehlt.

## Worum es geht
Galerkin-/Abschneide-Approximationen liefern endliche Matrizen mit beweisbarer Eigenwertlage, aber ohne gleichmäßige Kontrolle beim Limes. Turáns Partialsummen sind der Präzedenzfall, in dem der Limes nachweislich NICHT vererbt.

## Prüffrage
> **Gibt es eine gleichmäßige, von N unabhängige Schranke - oder nur punktweise Resultate pro N?**
