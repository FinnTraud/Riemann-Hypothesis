# F7 — Weiche Funktionentheorie (zu allgemein)

**Tier 1** (fatal — widerlegt die Idee sofort)  
**Betroffene Ansätze:** 2 von 45 (4.4 %)

> Das Argument benutzt nur allgemeine Eigenschaften holomorpher/ganzer Funktionen.

## Worum es geht
Voronin-Universalität: ζ approximiert im Streifen jede nullstellenfreie holomorphe Funktion. Eine Eigenschaft, die aus weicher Funktionentheorie folgt, gilt für sehr viele Funktionen und kann die kritische Gerade nicht auszeichnen.
