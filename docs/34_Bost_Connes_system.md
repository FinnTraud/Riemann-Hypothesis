# The Bost–Connes System (quantum statistics with ζ as the partition function)

**Category:** Spectral/algebraic approach (quantum statistical mechanics)
**Authors / year:** Jean-Benoît Bost & Alain Connes (1995); generalizations Connes–Marcolli, Laca–Raeburn and others
**Type:** C*-dynamical system with arithmetic symmetry
**Status:** Proven phase-transition phenomenon; not a direct RH proof, but structurally central to the 𝔽₁/NCG program

## Summary
The Bost–Connes system is a **quantum-statistical dynamical system** whose **partition function is exactly the Riemann ζ-function** and whose symmetries realize the **abelian Galois group** Gal(ℚ^ab/ℚ). It connects quantum statistics, class field theory, and the ζ-function, and is a key building block of Connes' noncommutative program (Doc. 10) and 𝔽₁ geometry (Doc. 30).

## Mathematical core (formulas, theorems, proof sketches)

### Construction
A C*-algebra A with a one-parameter group of automorphisms σ_t (time evolution), generated by a Hamiltonian H with spectrum {log n : n ≥ 1}:
```
H e_n = (log n) e_n,   σ_t(a) = e^{itH} a e^{−itH}.
```
The **partition function** at inverse temperature β:
```
Z(β) = Tr(e^{−βH}) = Σ_{n=1}^∞ e^{−β log n} = Σ_{n=1}^∞ n^{−β} = ζ(β).
```

### KMS states and phase transition
Equilibrium states are the **KMS_β states** (Kubo–Martin–Schwinger). **Theorem (Bost–Connes 1995):**
- For **β ≤ 1** (high temperature): a **unique** KMS state (symmetric phase).
- For **β > 1** (low temperature): **several** extremal KMS states; their partition function is ζ(β), and the Galois group Gal(ℚ^ab/ℚ) ≅ Ẑ* acts **freely transitively** on them.
- **Phase transition at β = 1** — exactly at the pole of ζ.

### Arithmetic symmetry
On the ground states (β → ∞) the absolute abelian Galois group acts; the values of the state on certain elements generate the maximal abelian field ℚ^ab (Kronecker–Weber: cyclotomic fields). So the system "knows" the explicit class field theory of ℚ.

### Generalization (Dedekind ζ)
For a number field K, the Connes–Marcolli system yields the **Dedekind zeta function** ζ_K as a partition function; the KMS states encode the class field theory of K.

## Significance / context for the RH
- Provides a **natural thermodynamic realization** of ζ — ζ appears as the partition function of a concrete operator H with spectrum {log n}.
- **Important:** this H has spectrum {log n} (primes/integers), **not** {γ_n} (zeros). It is therefore *not* directly the sought Hilbert–Pólya operator (Doc. 05), but realizes the *geometric* side. The passage to the spectral side (zeros) is exactly Connes' trace-formula step (Doc. 10).
- A structural foundation for 𝔽₁ (Doc. 30): the system carries the Galois/Frobenius symmetry needed for a "Spec(ℤ) over 𝔽₁".
